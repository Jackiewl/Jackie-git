# 学生端前端接口交付包

本交付包供“就业市场、岗位画像、学习路径”学生端前端开发使用，不包含数据库密码和后端源代码。

## 前端应先阅读

1. `前端对接说明.md`：如何请求接口、如何处理返回结果。
2. `接口清单.md`：15个接口分别对应哪个页面和功能。
3. `docs/field_dictionary.md`：公共字段以及W、R、T、d的含义。
4. `docs/error_codes.md`：错误处理规则。
5. `openapi.json`：机器可读的正式接口合同，可导入Apifox、Postman或其他接口工具。
6. `mock_data/`：每个接口的请求、成功结果和空结果示例。

## 开发阶段

前端页面可以先按照 `mock_data` 中的JSON制作，不需要连接数据库。

## 联调阶段

后端提供可访问的API地址后，把前端请求基础地址配置为：

```text
开发机本地：http://127.0.0.1:18100
局域网或服务器：http://后端提供的IP或域名:18100
```

所有业务接口均使用 `POST`，请求体和返回值均为JSON。

## 不应由前端完成的工作

- 不直接连接PostgreSQL。
- 不读取六个平台原始岗位表。
- 不计算岗位分类、W、R、T、d或学习路径。
- 不在前端保存数据库账号和密码。
- 不调用爬虫控制和AI分类控制功能。
