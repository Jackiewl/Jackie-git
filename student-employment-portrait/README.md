# 大学生就业画像系统学生端原型

这是一个纯前端可运行原型，围绕“就业市场 -> 岗位画像 -> 学习路径”的学生端主流程构建。

## 运行方式

在项目根目录启动静态服务：

```powershell
python -m http.server 18080
```

然后打开：

```text
http://127.0.0.1:18080/student-employment-portrait/
```

原型会优先读取 `前端接口交付包/mock_data` 中的 JSON；如果浏览器环境无法读取本地 mock 文件，则自动使用内置兜底数据。

## 已覆盖内容

- 就业市场首页：统计卡片、趋势图、热门岗位排行、招聘要求分布。
- 岗位画像：岗位搜索、岗位大类筛选、岗位能力画像、技能工具要求、相似岗位。
- 学习路径：PB/PF/JP/CP 四阶段路线、覆盖度指标、学习途径、任务详情。

## 边界

- 前端不展示原始招聘列表。
- 前端不计算 W、R、T、d 的正式算法，只做接口数据和产品逻辑展示。
- 学生个人掌握度 M、学习进度和测评结果保留给后续个人成长模块。
