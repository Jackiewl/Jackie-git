# 15个接口清单

统一基础地址用 `{API_BASE_URL}` 表示，例如 `http://127.0.0.1:18100`。

## 公共初始化

| 接口 | POST地址 | 页面用途 |
|---|---|---|
| 系统初始化 | `/api/v1/system/bootstrap/query` | 获取版本、数据更新时间、默认筛选条件和模块状态 |
| 岗位分类树 | `/api/v1/taxonomy/tree/query` | 获取5大类、28方向、117岗位完整树 |
| 市场筛选项 | `/api/v1/market/filter-options/query` | 获取城市、平台、状态、日期范围和时间颗粒度 |

## 就业市场

| 接口 | POST地址 | 页面用途 |
|---|---|---|
| 市场概览 | `/api/v1/market/overview/query` | 顶部统计卡片：通信相关、在招、新增、下架、净变化 |
| 招聘趋势 | `/api/v1/market/trend/query` | 日、周、月趋势以及上一周期对比 |
| 岗位分布 | `/api/v1/market/role-distribution/query` | 5大类、28方向或117岗位的数量和占比 |
| 岗位排行 | `/api/v1/market/role-ranking/query` | 需求最高、新增最多、增长最快、下降最多 |
| 城市分析 | `/api/v1/market/city-analysis/query` | 城市排名、城市趋势和城市热门岗位 |
| 招聘要求 | `/api/v1/market/requirements/query` | 薪资、学历、经验、行业和公司分布 |

## 岗位画像

| 接口 | POST地址 | 页面用途 |
|---|---|---|
| 岗位地图 | `/api/v1/roles/map/query` | 展示117个岗位卡片及招聘量、能力数、工具数 |
| 岗位完整画像 | `/api/v1/roles/profile/query` | 工作范围、市场摘要、能力、微能力、工具、相似岗位 |
| 岗位关系 | `/api/v1/roles/relations/query` | 117岗位节点和331组易混淆关系图 |
| 岗位对比 | `/api/v1/roles/compare` | 两个岗位的职责、能力、工具、市场和路径差异 |

## 学习路径

| 接口 | POST地址 | 页面用途 |
|---|---|---|
| 学习路径 | `/api/v1/learning-path/query` | 岗位目标、五项覆盖指标、PB/PF/JP/CP任务 |
| 实践任务详情 | `/api/v1/practice-tasks/detail/query` | 背景、目标、课程、步骤、验收、输出、T值、d值和依赖 |

## 页面调用关系

```text
网站启动
  ├─ system/bootstrap
  ├─ taxonomy/tree
  └─ market/filter-options

就业市场页面
  ├─ market/overview
  ├─ market/trend
  ├─ market/role-distribution
  ├─ market/role-ranking
  ├─ market/city-analysis
  └─ market/requirements

岗位画像页面
  ├─ roles/map
  ├─ roles/profile
  ├─ roles/relations
  └─ roles/compare

学习路径页面
  ├─ learning-path/query
  └─ practice-tasks/detail/query
```
