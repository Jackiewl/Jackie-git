# 前端对接说明

## 1. 请求规范

- 方法：`POST`
- 请求头：`Content-Type: application/json`
- 字段命名：`snake_case`
- 日期格式：`YYYY-MM-DD`，按北京时间解释，开始日和结束日都包含当天。
- 筛选数组为空表示全部，不表示没有数据。

就业市场公共筛选示例：

```json
{
  "filters": {
    "date_from": "2026-09-01",
    "date_to": "2026-09-15",
    "family_codes": [],
    "direction_codes": [],
    "role_codes": [],
    "city_codes": [],
    "platform_codes": [],
    "job_status": "active"
  },
  "options": {
    "granularity": "day",
    "limit": 10
  }
}
```

每个接口的准确请求示例见 `mock_data/对应模块/对应接口/request.json`。

## 2. 返回规范

成功：

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "meta": {
    "request_id": "uuid",
    "generated_at": "2026-09-16T10:00:00+08:00",
    "data_updated_at": "2026-09-16T08:00:00+08:00",
    "timezone": "Asia/Shanghai"
  }
}
```

失败：

```json
{
  "code": 40001,
  "message": "请求参数无效",
  "data": null,
  "meta": {
    "request_id": "uuid"
  }
}
```

前端统一处理逻辑：

```javascript
const result = await response.json();

if (result.code === 0) {
  return result.data;
}

throw new Error(result.message);
```

## 3. 请求封装示例

```javascript
const API_BASE_URL = import.meta.env.VITE_API_BASE_URL;

export async function postApi(path, payload = {}) {
  const response = await fetch(`${API_BASE_URL}${path}`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(payload)
  });

  const result = await response.json();

  if (result.code !== 0) {
    throw new Error(result.message || "接口请求失败");
  }

  return result.data;
}
```

调用岗位画像：

```javascript
const profile = await postApi("/api/v1/roles/profile/query", {
  role_code: "P1.1.1"
});
```

## 4. Mock开发

前端尚未连接后端时，可直接读取对应的 `success.json` 制作页面：

```text
request.json  请求示例
success.json  正常有数据时的data内容
empty.json    查询结果为空时的data内容
```

注意：Mock文件保存的是统一响应中的 `data` 部分。真实接口返回时，外层还包含 `code`、`message` 和 `meta`。

## 5. OpenAPI使用

`openapi.json` 可以直接导入：

- Apifox
- Postman
- Swagger Editor
- 前端类型生成工具

OpenAPI文件是字段类型和地址的正式合同；Mock数据用于观察真实页面数据形态。

## 6. 联调检查

- 不在代码中写死 `127.0.0.1`，统一使用环境变量配置基础地址。
- 页面加载、空数据、参数错误和服务不可用四种状态都要处理。
- 列表没有数据时按 `[]` 处理。
- 单个可空字段按 `null` 处理。
- 比例字段范围为0到1，前端显示百分比时乘以100。
- 前端不要重新计算W、R、T、d，只展示接口返回的数值和中文标签。
